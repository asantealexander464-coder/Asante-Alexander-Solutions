# Asante Alexander Solutions

This project is a simple static website for Asante Alexander Solutions.

## Publish with GitHub Pages

1. Create a GitHub repository named `asantealexandersolutions` or `asantealexander`.
2. Upload all files from this folder to the repository.
3. In the repository settings, open Pages.
4. Under Source, choose `Deploy from a branch`.
5. Select the `main` branch and the `/root` folder.
6. Save and wait for deployment.

Your site will be available at:
- https://your-username.github.io/asantealexandersolutions/
- or https://your-username.github.io/asantealexander/
